# EU-Product-Packaging-compliance
European companies increasingly need reliable product, packaging and material information to address EPR, PPWR and emerging Digital Product Passport requirements.

The challenge is not only regulatory interpretation. A significant part of the problem is data: fragmented product records, packaging information, supplier declarations, material classifications, movements and evidence.

Packaging Data Lab explores whether a common, traceable product and packaging data model can provide a reusable foundation for these different use cases.
